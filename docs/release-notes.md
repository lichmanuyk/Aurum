# Что добавлено в персональном Aurum

Это список для проверки функций в браузере, а не технический журнал коммитов.
Все пункты ниже слиты в personal. Последняя независимо проверенная рабочая версия на домашнем Mac — после PR #31; развёртывание PR #34–#49 ещё не подтверждено. Даты слитых PR здесь не восстанавливаются по памяти.

- **Мультивалютный учёт и перенос Monefy.** Счета сохраняют свои валюты, реальные переводы — собственные суммы и курсы; начальные остатки и корректировки отделены от доходов/расходов. Проверить: «Счета», «Операции», «Отчёты».
- **Криптопортфель и котировки.** Текущие количества монет входят в капитал и переоцениваются по котировкам; исходная стоимость денежного прокси не считается вторым активом. Проверить: «Криптовалюта», «Капитал».
- **Покупка/продажа активов — PR #13.** Связанная операция меняет счёт и актив, учитывает комиссию, не загрязняет обычные доходы/расходы. Проверять на тестовой базе, без фиктивных сделок в личной истории.
- **Цели, регулярные платежи и проверки повседневных сценариев.** Цели резервируют средства без изменения общего капитала; регулярные платежи подтверждаются пользователем. Проверить соответствующие разделы, без лишнего списания ради знакомства.
- **Валюты отображения — PR #31 и #34.** В настройках задаются общая валюта сводок и исключения для дашборда, капитала, крипты, движения денег и отчётов; в шапке доступен временный просмотр. Проверить настройки и сравнить экраны: суммы исходных операций сохраняются.
- **Справочные курсы — PR #36.** На дашборде показаны сохранённые официальные USD/EUR/BYN/RUB с датой и источником; ошибки загрузки можно повторить. Первоначальные пары к PLN дополнены карточкой периодов в PR #49.
- **Аналитика движения денег — PR #38.** Доходы/расходы можно независимо скрывать; два рейтинга категорий ведут в отчёты с периодом и подкатегориями. Проверить «Движение денег», переход и обновление страницы.
- **Периоды дашборда — PR #40.** «Всё время», весь год и месяц используют единые серверные границы; будущие операции не попадают в текущую сводку и связанный список. Проверить выбор периода и «Все операции».
- **Связь пончиков со списками — PR #42.** Наведение, клавиатура и касание сопоставляют сектора со строками; на широком экране есть линия, одинаковые цвета различаются узорами. Проверить расходы дашборда и аллокацию монет/сетей; сплошные цвета и обходная линия дашборда добавлены следующим PR #46.
- **Сортировка капитала — PR #44, принято 2026-09-26.** Классы и ручные активы упорядочены по стоимости в валюте капитала, сегменты и строки выделяются согласованно. Проверить «Капитал»: эквиваленты рядом с исходными суммами, прочерк без оценки и снятие выделения.
- **Сплошные цвета пончика расходов — PR #46, принято 2026-09-26.** Секторы и маркеры строк различаются цветами без штриховки; линия активной строки идёт вокруг пончика и не обрезается на коротком списке. Проверить расходы дашборда на широком экране; на телефоне сохраняется подсветка без тесной линии.
- **Курсы за период — PR #49, принято 2026-09-26.** Дашборд показывает USD/EUR к PLN и BYN/RUB за доллар, текущие курсы или среднее выбранного периода с мини-графиками. Проверить переключение периода; недостающую историю можно загрузить явно, с видимым интервалом и продолжением после сбоя.
- **Защита данных и запуск.** Постоянное приложение отделено от тестов; ежедневные копии настроены на 13:00 в iCloud с хранением 30 дней, восстановление отдельной копии проверялось. Для каждого нового развёртывания проверять запуск и свежий backup отдельно; зелёный CI не доказывает, что домашний Docker уже обновлён.

## Как вести этот файл

После приёмки функционального PR добавлять 1–2 предложения: наблюдаемое изменение, номер PR, где попробовать. Запланированные возможности не перечислять как реализованные; факт развёртывания подтверждать отдельно. Не включать личные суммы, ключи и технический перечень файлов.
