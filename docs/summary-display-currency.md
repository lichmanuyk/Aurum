# Валюта сводок

На дашборде, в капитале и криптовалютах доступен переключатель «Валюта сводки»:
основная валюта приложения или явно PLN / USD / EUR. Выбор общий для этих
трёх страниц и сохраняется в localStorage текущего браузера. Другой браузер
может выбрать другую валюту. Одновременный второй эквивалент пока не добавлен.

API сводок дашборда, капитала, криптоостатков и криптоистории принимает
необязательный параметр `currency`. Он изменяет только FXConverter текущего
запроса. AppSettings не перезаписывается; запрос без параметра использует
основную валюту. Неверный ISO-код возвращает 422, отсутствие нужных исторических
курсов — прежнюю явную ошибку FX, а не пересчёт по сегодняшней цене или 1:1.

Доходы/расходы, категории и история капитала пересчитываются по существующим
правилам исторических дат. Итоги, разбивки, подсказки графиков и криптотаблица
форматируются в выбранной валюте через локальный React-контекст. Ключи кеша
включают валюту: ответы разных валют не смешиваются при переключении.

Список последних операций и обычные счета/активы сохраняют свои исходные
валюты. Формы создания операций и активов продолжают использовать основную
или явно заданную валюту. История сделок показывает реальную quote_currency.
Процентные показатели рыночной динамики крипты остаются показателями её
исходной валюты котировки, обозначенной в карточке показателя.

EUR/USD включены в план NBP даже при отсутствии счетов в этих валютах.
Автозагрузка покрывает последние 14 дней; если для новой валюты просмотра
не хватает прошлых публикаций, используется существующая загрузка всей
истории в настройках. Миграции базы и изменения формата бэкапа не нужны.

Проверки: независимые исторические итоги, одновременные запросы разных валют,
неизменность настроек/операций/криптоостатков, неизвестная себестоимость,
валидация валюты, сохранение выбора при переходах и перезагрузке страницы.
